## ch5 Nâng cao: Claude Code và nền tảng

[F-54] Claude Code kết hợp một model biết suy luận về mã nguồn với các công cụ dựng sẵn để thao tác file, tìm kiếm, chạy lệnh và truy cập web. — cc-features-overview
[F-55] CLAUDE.md là ngữ cảnh cố định mà Claude thấy ở mọi phiên làm việc, thường dùng cho quy ước dự án kiểu luôn làm theo một cách nhất định. — cc-features-overview
[F-56] Skill là file markdown chứa kiến thức, quy trình hoặc chỉ dẫn tái sử dụng được; người dùng gọi bằng lệnh hoặc Claude tự nạp khi thấy phù hợp. — cc-features-overview
[F-57] Subagent là các phiên làm việc chạy vòng lặp riêng, trong ngữ cảnh tách biệt, và chỉ trả về bản tóm tắt cho cuộc trò chuyện chính. — cc-features-overview
[F-58] Hook cho phép chạy script, yêu cầu HTTP, gọi công cụ MCP, prompt hoặc subagent mỗi khi Claude Code đến một sự kiện vòng đời nhất định, đảm bảo việc đó luôn xảy ra dù agent làm gì. — cc-features-overview
[F-59] Plugin là lớp đóng gói: một plugin gói skill, hook, subagent và MCP server thành một gói cài đặt duy nhất, dùng khi muốn tái sử dụng cùng một thiết lập trên nhiều kho mã hoặc chia sẻ cho người khác. — cc-features-overview
[F-60] MCP giúp Claude Code kết nối tới hàng trăm công cụ và nguồn dữ liệu bên ngoài; MCP server cho Claude Code quyền truy cập công cụ, cơ sở dữ liệu và API của người dùng. — cc-mcp-docs
[F-61] Nên kết nối một MCP server khi người dùng thấy mình liên tục sao chép dữ liệu từ công cụ khác vào khung chat, ví dụ hệ thống theo dõi lỗi hay bảng điều khiển giám sát. — cc-mcp-docs
[F-62] Anthropic giới thiệu Model Context Protocol là chuẩn mở, thống nhất cách kết nối hệ thống AI với nguồn dữ liệu, thay cho các cách tích hợp rời rạc trước đó. — model-context-protocol-news
[F-63] Agent SDK cho phép nhúng agent của Claude Code vào ứng dụng Python hoặc TypeScript riêng, dùng chung công cụ và cách quản lý ngữ cảnh với Claude Code. — agent-sdk-overview
[F-64] Theo tài liệu Agent SDK, nhà phát triển có thể gọi trực tiếp API của Claude từ mã nguồn, hoặc dùng Managed Agents là agent được Anthropic vận hành và host sẵn, cấu hình qua API. — agent-sdk-overview

## ch7 An toàn và tổng kết

[F-81] Anthropic dùng các model phát hiện để gắn cờ nội dung có khả năng gây hại dựa trên Usage Policy. — user-safety-help
[F-82] Khi model phát hiện gắn cờ nội dung có hại, bộ lọc an toàn có thể chặn câu trả lời tương ứng. — user-safety-help
[F-83] Anthropic có thể tạm thời áp bộ lọc an toàn tăng cường cho người dùng vi phạm chính sách nhiều lần, và gỡ bỏ sau một thời gian không vi phạm. — user-safety-help
[F-84] Anthropic thừa nhận các công cụ an toàn này không hoàn hảo, có thể có trường hợp gắn cờ sai hoặc bỏ sót, và mời người dùng phản hồi qua email. — user-safety-help
[F-85] Chat ẩn danh không được dùng để huấn luyện model, và dữ liệu được giữ 30 ngày theo mặc định trừ khi tổ chức đặt thời gian lưu khác. — incognito-chats-help
[F-86] Người dùng có thể bật chat ẩn danh bằng cách bấm biểu tượng hình bóng ma ở góc trên bên phải màn hình. — incognito-chats-help
[F-87] Theo mặc định Claude không tự lưu các chủ đề nhạy cảm vào bộ nhớ trừ khi người dùng bật tính năng đó lên, nên người dùng nên biết điều này trước khi nhập dữ liệu nhạy cảm. — memory-how-it-works-help
